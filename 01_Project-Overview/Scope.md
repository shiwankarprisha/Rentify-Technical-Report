# Scope

## In Scope

The Rentify system focuses on:

- Rental property discovery
- Property search and filtering
- Property details and listing information
- Ownership and document verification workflow
- Administrative listing review
- Physical verification through verification partners
- Verified and flagged listing states
- Safety and credibility information
- Tenant feedback
- Scam awareness
- Legal and tenancy guidance
- Government housing scheme information
- Role-based workflows

## Current Prototype Scope

The current prototype demonstrates the above workflows using a frontend-based interactive implementation with simulated data and browser local storage for demo-state persistence.

## Proposed Production Scope

The proposed production system may include:

- Backend APIs
- Persistent database
- Authentication and authorization
- Actual document upload and verification
- Government or registry integrations where available
- Location and amenity APIs
- Advanced recommendation systems
- AI-assisted document verification
- Advanced fraud and scam detection

## Out of Scope for Current Prototype

The following are not currently implemented:

- Production backend
- Production database
- Real authentication
- Live government registry verification
- Actual document upload
- AI-based document verification
- Machine-learning recommendation
- Live external location-service integration
