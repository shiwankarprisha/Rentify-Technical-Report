# Non-Functional Requirements

## NFR-01: Usability

The interface should be simple and understandable for renters with different levels of technical familiarity.

## NFR-02: Responsiveness

The web interface should adapt to commonly used desktop and mobile screen sizes.

## NFR-03: Performance

Property search, filtering and navigation should provide responsive interaction under normal operating conditions.

## NFR-04: Security

User information and ownership-related documents should be protected from unauthorized access in the production system.

## NFR-05: Privacy

Sensitive identity and ownership information should be collected and stored only when required and handled according to applicable privacy and security requirements.

## NFR-06: Reliability

Verification records and listing status changes should remain consistent and traceable.

## NFR-07: Maintainability

The system should use modular components so that individual modules can be developed, tested and modified independently.

## NFR-08: Scalability

The proposed production architecture should support expansion to additional cities, properties and users.

## NFR-09: Transparency

Verification status and relevant decision-support information should be presented clearly to renters.

## NFR-10: Explainability

Recommendation or ranking mechanisms should provide understandable criteria rather than relying only on opaque scores.

## NFR-11: Availability

The proposed production platform should be designed for reliable access during normal service operation.

## NFR-12: Auditability

Important verification actions and status changes should be traceable through appropriate records or audit logs.

## Prototype Note

The current prototype is intended for demonstration and does not provide production-grade authentication, security, scalability or availability guarantees.
