# 03 — Requirements

This section defines the functional and non-functional requirements of the Rentify system and identifies the primary user roles and use cases.

## Contents

- `Functional-Requirements.md` — Functional capabilities required by the system
- `Non-Functional-Requirements.md` — Quality, security, usability and operational requirements
- `User-Roles.md` — Responsibilities of the four primary system roles
- `Use-Cases.md` — Major user interactions and workflows

## Primary User Roles

Rentify supports four primary roles:

1. **Customer / Renter**
2. **Vendor / Property Owner**
3. **Admin / Registrar**
4. **Verification Partner**

## Major Functional Areas

The requirements cover:

- Property discovery
- Search and filtering
- Property details
- Property submission
- Ownership information
- Administrative review
- Verification assignment
- Physical verification
- Verified and flagged listing states
- Discrepancy reporting
- Rental assistance
- Tenant feedback
- Decision support
- Role-based workflows

## Requirement Boundary

The requirements describe both the intended system capabilities and the distinction between the current interactive prototype and the proposed production system.

The current prototype demonstrates the major user workflows using simulated data and browser local storage.
