# User Roles

Rentify is organized around four primary roles.

## 1. Customer / Renter

The customer is the primary consumer of the platform.

### Responsibilities

- Explore rental properties
- Search and filter listings
- View property details
- Review verification status
- Examine safety and credibility information
- Access rental assistance
- Submit feedback
- Make an informed rental decision

---

## 2. Vendor / Property Owner

The vendor represents the property owner or listing provider.

### Responsibilities

- Submit rental properties
- Provide property information
- Provide ownership-document information
- Provide identity information
- Track listing verification status

---

## 3. Admin / Registrar

The administrator manages the platform's verification operations.

### Responsibilities

- Review submitted listings
- Examine ownership information
- Assign verification partners
- Monitor active verification visits
- Review verification outcomes
- Approve or flag listings
- Maintain verification workflow records

---

## 4. Verification Partner

The verification partner performs field-level verification.

### Responsibilities

- View assigned properties
- Conduct physical inspection
- Confirm location/GPS information
- Inspect original ownership documents
- Verify physical access/vacancy
- Record field observations
- Confirm verification or report discrepancies

---

## Role Interaction

The primary verification interaction is:

**Vendor → Admin → Verification Partner → Verified / Flagged Listing**

The customer primarily interacts with the resulting listing information and decision-support features.
