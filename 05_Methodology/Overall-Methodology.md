# Overall Methodology

Rentify follows a renter-centric decision-support methodology based on four stages:

**DISCOVER → VERIFY → UNDERSTAND → DECIDE**

## Stage 1 — Discover

Customers search and filter rental properties using parameters such as:

- City
- Locality
- Property type / BHK
- Maximum rent
- Verification status

## Stage 2 — Verify

Listings pass through a structured verification workflow.

The workflow involves:

**Vendor → Admin → Verification Partner → Verified / Flagged**

The verification process considers ownership information, documents and physical property checks.

## Stage 3 — Understand

Customers examine additional information such as:

- Property specifications
- Verification status
- Safety information
- Credibility information
- Tenant feedback
- Scam awareness
- Legal and tenancy guidance
- Government housing schemes

## Stage 4 — Decide

The customer combines the available property, verification and assistance information to make a more informed rental decision.

## Supporting Methodology

The system is divided into role-specific workflows:

- Customer workflow
- Vendor workflow
- Admin workflow
- Verification Partner workflow

## Current Prototype

The prototype demonstrates the complete conceptual workflow using simulated data, deterministic filtering/ranking and browser local storage.

## Proposed Extensions

Future development can introduce:

- Persistent backend services
- Advanced recommendation models
- AI-assisted document verification
- Automated fraud detection
- External registry integrations
- Location and amenity APIs
