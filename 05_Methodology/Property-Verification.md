# Property Verification Methodology

Rentify uses a structured, multi-stage verification workflow to improve transparency around rental listings.

## Verification Stages

### 1. Vendor Submission

The property owner provides:

- Property details
- Ownership-proof information
- Document type
- Registration number
- Government ID information

### 2. Administrative Review

The Admin reviews the submitted information and determines whether the listing should proceed to field verification or be flagged.

### 3. Partner Assignment

An eligible Verification Partner is assigned to the property.

### 4. Physical Verification

The Verification Partner performs an on-site checklist covering:

- GPS/location confirmation
- Original ownership document inspection
- Physical keys testing
- Vacancy confirmation
- Ownership confirmation through available local/society verification

### 5. Verification Outcome

The listing is assigned one of the following states:

- Pending
- In-Review
- Verified
- Flagged

## Verification Transparency

For verified listings, Rentify presents verification-related information to the customer rather than simply displaying the property as trustworthy.

For flagged listings, the system displays the discrepancy information and warns the customer against proceeding with risky transactions.

## Risk Limitation

Verification is intended to reduce risk and improve transparency. It does not guarantee that a rental transaction is completely risk-free.

## Prototype Implementation

The current prototype simulates document and field verification using predefined data and interactive checklists.

Actual government-registry verification, secure document storage and automated document authentication are proposed for future production development.
