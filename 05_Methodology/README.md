# 05 — Methodology

This section explains the methodology used by Rentify to support the rental decision-making process.

## Core Methodology

**DISCOVER → VERIFY → UNDERSTAND → DECIDE**

## Methodology Components

- Overall rental decision-support methodology
- Property verification methodology
- Recommendation and ranking methodology
- Scam detection and risk-awareness approach
- Rental assistance methodology

The current prototype demonstrates the core workflow using simulated data and deterministic logic.

Advanced AI/ML, automated document verification and external service integrations are proposed future capabilities.
