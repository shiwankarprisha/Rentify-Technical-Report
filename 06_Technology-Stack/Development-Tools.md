# Development Tools

The Rentify prototype and project documentation use a combination of development and collaboration tools.

## VS Code

Visual Studio Code is used as the primary development environment for working with the frontend source code and project files.

## Git

Git is used for version control and tracking project changes.

## GitHub

GitHub is used for repository hosting, documentation management and project collaboration.

The technical documentation is maintained in the:

**Rentify-Technical-Report**

repository.

## Vite

Vite is used to run the React development environment and create production frontend builds.

## Browser Developer Tools

Browser developer tools can be used to inspect:

- UI behaviour
- Console output
- Local storage
- Network activity
- Responsive layouts

## API Testing

Postman is identified as a proposed development/testing tool for future backend REST APIs.

The current frontend-only prototype does not require backend API testing.

## Testing Tools

Jest is identified in the proposed technology stack for future automated testing of application logic.

## Development Approach

The project follows an iterative development approach:

**Research → Requirements → Design → Prototype → Testing → Future Full-Stack Development**
