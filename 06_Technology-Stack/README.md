# 06 — Technology Stack

This section documents the technologies used in the Rentify prototype and the technologies proposed for a production implementation.

## Current Prototype

The current implementation is a frontend-based interactive prototype using:

- React 19
- React Router 7
- Tailwind CSS
- Lucide React
- Vite
- React Context
- Browser Local Storage

## Proposed Production Technologies

The production system can be extended using:

- Node.js / Express.js
- MongoDB or PostgreSQL
- Authentication and authorization
- Secure document storage
- Location and mapping services
- Notification services
- Appropriate external verification integrations

## Development Tools

The project uses or proposes:

- Visual Studio Code
- Git
- GitHub
- Postman
- Jest
- Browser Developer Tools

## Implementation Boundary

The distinction between implemented and proposed technologies is maintained throughout the technical report.

The current prototype validates the user interface and major workflows, while backend, database, external API and advanced AI/ML capabilities remain part of the proposed production system or future scope.
