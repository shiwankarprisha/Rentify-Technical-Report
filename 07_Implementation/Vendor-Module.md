# Vendor Module

The Vendor Module allows property owners to submit rental properties and monitor their verification status.

## Vendor Dashboard

The dashboard displays listing statistics including:

- Total Managed
- Verified Active
- In Pipeline
- Flagged Discrepancies

## Property Submission

The vendor can select:

**Submit New Property**

The submission form captures:

- Property title
- City
- Area / locality
- Property type
- Monthly rent
- Security deposit
- Description
- Ownership proof
- Document type
- Deed registration number
- Government ID information

## Supported Document Types

The prototype provides options such as:

- Index II
- 7/12
- Property Tax

## Submission Workflow

The vendor completes the required information and selects:

**Submit for Title Review**

The submitted property enters the verification workflow with the appropriate listing status.

## Document Simulation

The prototype represents ownership-document submission using simulated digital documents.

Actual document upload and secure document storage are not implemented.

## Listing Tracking

Vendors can monitor the lifecycle of their submitted properties through statuses such as:

- Pending
- In-Review
- Verified
- Flagged

## Implementation Status

The Vendor Module is implemented as part of the current frontend prototype.

Production authentication, actual document storage and backend processing are proposed future extensions.
