# 08 — Testing and Validation

This section documents the testing approach, test scenarios, validation process and limitations of the Rentify prototype.

## Contents

- `Testing-Strategy.md` — Testing approach and levels
- `Test-Cases.md` — Functional and workflow test cases
- `Validation.md` — Validation of the proposed user workflows
- `Limitations.md` — Current prototype limitations

## Testing Focus

Testing focuses on:

- Property discovery
- Search and filtering
- Property details
- Vendor submission
- Administrative review
- Verification-partner workflow
- Verified and flagged listing states
- Rental assistance
- Feedback
- Prototype state persistence

## Validation Principle

The current validation demonstrates that the proposed workflow can be represented through an interactive prototype.

It does not claim measured fraud reduction, legal effectiveness or production-level system performance.
