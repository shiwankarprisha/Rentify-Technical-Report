# Validation

## Validation Objective

Validation checks whether the Rentify prototype demonstrates the intended solution to the identified rental decision-making problem.

## Workflow Validation

The prototype provides an end-to-end conceptual workflow:

**DISCOVER → VERIFY → UNDERSTAND → DECIDE**

### Discover

Customers can search and filter rental properties.

### Verify

The prototype demonstrates a structured listing verification workflow involving:

**Vendor → Admin → Verification Partner**

### Understand

Customers can examine:

- Property details
- Verification information
- Safety information
- Credibility information
- Tenant feedback
- Rental assistance

### Decide

The combined information is intended to help renters make a more informed decision.

## Role Validation

The prototype provides separate workflows for:

- Customer / Renter
- Vendor / Property Owner
- Admin / Registrar
- Verification Partner

Each role has actions corresponding to its intended responsibilities.

## Verification Lifecycle Validation

The prototype demonstrates:

**Pending → In-Review → Verified / Flagged**

This allows both successful and discrepancy scenarios to be demonstrated.

## Decision-Support Validation

The prototype makes verification status and relevant property information visible to the renter instead of treating every listing as equally trustworthy.

## Prototype Validation Boundary

The validation demonstrates the feasibility of the proposed user workflows and interface.

It does not establish:

- Real-world fraud reduction
- Legal effectiveness
- Accuracy of government-registry verification
- Production security
- Scalability
- Effectiveness of machine-learning models

These require a deployed system, real data and controlled evaluation.
