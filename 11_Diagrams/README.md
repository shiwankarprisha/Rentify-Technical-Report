# 11 — Diagrams

This section contains the system-design diagrams created for the Rentify project.

The diagrams provide visual representations of the system architecture, user interactions, data movement, verification workflow and module relationships.

## Contents

### 1. System Architecture

`System-Architecture.png`

Provides a high-level representation of the Rentify system architecture, including users, application layers, major services and data components.

### 2. User Flow

`User-Flow.png`

Illustrates the major user journeys through the Rentify platform, covering the interactions of customers, vendors, administrators and verification partners.

### 3. Data Flow Diagram

`Data-Flow-Diagram.png`

Represents how property, verification, feedback and decision-support information moves through the Rentify system.

### 4. Verification Workflow

`Verification-Workflow.png`

Illustrates the property verification lifecycle:

**Pending → In-Review → Verified / Flagged**

and the primary verification interaction:

**Vendor → Admin → Verification Partner → Verified / Flagged**

### 5. Module Architecture

`Module-Architecture.png`

Shows the major Rentify modules and their relationships, including customer, vendor, admin, verification-partner, property/verification, assistance and feedback-related modules.

## Purpose

These diagrams support the technical documentation by providing visual representations of the system design and major workflows.

They correspond to the architecture and methodology described in:

- `04_System-Design/`
- `05_Methodology/`
- `07_Implementation/`

## Diagram Status

All diagrams in this folder are prepared for use in the Rentify technical report and project presentation.

The diagrams represent the proposed system design and the current prototype workflow where applicable. Production-only components should be interpreted as proposed architecture rather than implemented functionality.
