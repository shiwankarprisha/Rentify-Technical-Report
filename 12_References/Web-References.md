This file contains reliable online sources used to support factual claims in the Rentify technical documentation.

### Cybercrime and Fraud Sources

## Source Selection

Preference is given to:

1. Official government sources
2. Institutional sources
3. Original research publications
4. Official company/platform sources
5. Reputable news sources for documented cases

Unverified statistics and unsupported claims are not used as evidence in the technical report.
