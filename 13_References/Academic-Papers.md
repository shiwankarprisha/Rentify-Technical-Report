# Academic Papers

This file contains the academic literature reviewed during the development of Rentify.

## 1. Rental Property Recommendation Systems

Research on recommendation systems provides the foundation for helping users identify properties according to their preferences, budget, location, and other requirements.

The reviewed literature indicates that recommendation approaches can improve the process of matching users with suitable rental properties.

## 2. Fake Listing and Fraud Detection

Existing research has explored the detection of fraudulent or misleading property listings using listing characteristics, textual information, behavioral patterns, and machine-learning techniques.

This literature supports Rentify's focus on identifying potential discrepancies and presenting verification information transparently.

## 3. Property and Document Verification

Research related to property verification and digital document validation demonstrates the importance of establishing trust in property-related transactions.

Rentify incorporates verification as an explicit workflow rather than treating a listing as trustworthy solely because it is published on a platform.

## 4. Research Gap

The reviewed literature generally addresses recommendation, fraud detection, or verification as separate problems.

Rentify's contribution is primarily the **integration of property discovery, verification, contextual information, and rental assistance into a unified renter-facing decision-support workflow**.

## 5. Note on Implementation

The current Rentify prototype uses deterministic filtering and ranking and a simulated verification workflow. Advanced machine-learning and AI-based approaches identified in the literature are considered future enhancements rather than implemented capabilities.
