# RENTIFY – One-Stop Rental Assistance Platform

> **Transparent Rental Decision Support for Safer and More Informed Rental Decisions**

## 📌 About the Project

Rentify is a unified rental assistance platform designed to help renters discover, verify, understand, and make informed decisions about rental properties.

The platform combines:

- 🏠 Property Discovery
- 🔐 Property & Owner Verification
- 📍 Location-Based Information
- 📋 Rental Assistance & Guidance
- 👥 Role-Based Verification Workflow

The core approach of Rentify is:

**DISCOVER → VERIFY → UNDERSTAND → DECIDE**

---

## 🎯 Problem Statement

The current rental process is fragmented and trust-sensitive. Renters often have to use multiple sources to:

- Find suitable rental properties
- Determine whether a listing and owner are trustworthy
- Understand locality and nearby facilities
- Identify potential rental scams
- Access legal and tenancy guidance
- Find relevant housing schemes and assistance

This creates information gaps and increases the difficulty of making a safe and informed rental decision.

---

## 💡 Proposed Solution

Rentify proposes a unified platform that brings property discovery, verification, location-based information, and rental assistance into a single renter-facing workflow.

The system introduces a structured verification workflow involving:

**Vendor → Admin → Verification Partner → Verified Listing**

along with rental guidance and decision-support information for customers.

---

## 👥 User Roles

Rentify considers four primary roles:

| Role | Responsibility |
|---|---|
| Customer / Renter | Search and evaluate rental properties |
| Vendor / Property Owner | Submit and manage property listings |
| Admin | Review listings and manage verification workflow |
| Verification Partner | Perform physical property verification |
